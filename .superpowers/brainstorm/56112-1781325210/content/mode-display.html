两种模式展示方案

STRICT（严格）和 LOOSE（宽松）从侧边栏移到选股页面，用什么形式？

A

双指标卡并排

两张统计卡片横向排列，每张包含模式名 + 标签（连板数/胜率/Sharpe）+ 小字说明。红色/绿色区分，带微弱发光边框

B

胶囊标签行

在"选股结果"标题旁一行小胶囊：[🔴 STRICT 3连板 70%] [🟢 LOOSE 2连板 60%]，hover 展开详情。不占空间，轻量优雅

C

可折叠信息条

一条横向暗色信息栏，折叠时显示"◆ 筛选模式: STRICT + LOOSE"，展开后显示完整对比表。适合不想信息过载的场景
